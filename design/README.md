# Source material

Kept for provenance. Neither file is part of the build.

- **`Peru_Trip_Content.md`** — the source of truth for all copy and data. Everything in `src/content/` is transcribed from here; the anchor slugs in `categories.json` and the day files match its Quick Links TOC exactly. If a fact changes, change it here and in the matching content collection.

- **`claude-design-comp.html`** — the Claude Design layout the visual system comes from: the ink/cream/pink/gold palette, Anton + Work Sans, square edges, numbered sections, the 520 px phone column, and the component treatments (day disclosure rows, reservation boxes, Little Black Book panels, weather cards). It's a self-unpacking bundle — open it in a browser to view.

  The fonts in `public/fonts/` were extracted from this bundle and are self-hosted so the guide works offline.

Deliberate departures from the comp are listed at the bottom of the root `README.md`.
